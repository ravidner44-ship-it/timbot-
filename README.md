# 🍩 Tell Tims Auto-Coupon Telegram Bot
**Developer:** SIDHU ([@deep_xd5](https://t.me/deep_xd5))

An AI-powered Telegram Bot that scans Tim Hortons (Tell Tims) receipts via OCR, automatically solves the 23-step Qualtrics customer feedback survey with 5-star positive ratings, and instantly returns the Validation Coupon Code.

## 🚀 Features
- **Photo OCR Scanning**: Direct receipt photo analysis & code extraction.
- **Multi-Photo Batching**: Send 5-10 receipt photos at once for batch processing.
- **Direct Code Auto-Detect**: Send numbers directly without commands.
- **Punjabi Swagger Theme**: Custom dialogues, greetings, and developer branding.
- **24/7 Free Cloud Ready**: Dockerfile & requirements ready for Render/Koyeb/Railway.

## 📦 Deployment
Deploy with Docker on Render.com or Koyeb:
- Set Environment Variable: `TELEGRAM_BOT_TOKEN`
- Runtime: `Docker`
